**Topic:** Hashing
**Difficulty:** Easy
**Solution file:** [`011-Majority-Element-Basic.java`](./011-Majority-Element-Basic.java)

## Problem

Given an array, find the element that appears more than n/2 times, using a hash map of frequencies.

## Technique Reminder

Use hash maps/sets for O(1) average lookups to avoid brute-force nested loops.

**Hint:** Ask: what do I need to remember about elements I've already seen?

## Example

```
Input:  arr = [2,2,1,1,1,2,2]
Output: 2
```

## Constraints (typical range — adjust to the exact source problem if it differs)

- 1 <= n <= 10^5
- Values fit in standard 32-bit integer range
