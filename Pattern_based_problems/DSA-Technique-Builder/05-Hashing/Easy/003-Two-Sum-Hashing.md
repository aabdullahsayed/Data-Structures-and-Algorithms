**Topic:** Hashing
**Difficulty:** Easy

## Problem

Given an array and a target, find the indices of two numbers that add up to the target, using a hash map for a single O(n) pass.

## Technique Reminder

Use hash maps/sets for O(1) average lookups to avoid brute-force nested loops.

**Hint:** Ask: what do I need to remember about elements I've already seen?

## Example

```
Input:  arr = [2,7,11,15], target = 9
Output: [0,1]
```
