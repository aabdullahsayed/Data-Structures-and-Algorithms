**Topic:** Linked List
**Difficulty:** Medium
**Solution file:** [`007-Remove-Nth-Node-From-End.java`](./007-Remove-Nth-Node-From-End.java)

## Problem

Given the head of a linked list, remove the nth node counting from the end, and return the head — do it in a single pass using two pointers offset by n.

## Technique Reminder

Core singly/doubly linked list manipulation.

**Hint:** Draw the pointers on paper before coding; watch out for null pointers and losing references.

## Example

```
Input:  list = 1->2->3->4->5, n = 2
Output: 1->2->3->5
```

- Values fit in standard 32-bit integer range
