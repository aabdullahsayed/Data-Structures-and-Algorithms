# 008. Add Two Numbers

**Topic:** Linked List
**Difficulty:** Medium
**Solution file:** [`008-Add-Two-Numbers.java`](./008-Add-Two-Numbers.java)

## Problem

Given two non-negative integers represented as linked lists in reverse digit order (least significant digit first), add the two numbers and return the sum as a linked list in the same format.

## Technique Reminder

Core singly/doubly linked list manipulation.

**Hint:** Draw the pointers on paper before coding; watch out for null pointers and losing references.

## Example

```
Input:  l1 = 2->4->3 (342), l2 = 5->6->4 (465)
Output: 7->0->8 (807)
```
