## Problem

Given the heads of two singly linked lists, find the node at which the two lists intersect (share the same tail), or null if they never intersect.

## Technique Reminder

Core singly/doubly linked list manipulation.

**Hint:** Draw the pointers on paper before coding; watch out for null pointers and losing references.

## Example

```
Input:  two lists that share a common tail starting at node c1
Output: node c1
```
