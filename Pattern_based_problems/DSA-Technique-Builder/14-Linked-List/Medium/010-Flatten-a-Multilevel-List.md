**Topic:** Linked List

## Problem

Given a multilevel doubly linked list where some nodes have an extra 'child' pointer to a separate sub-list, flatten it into a single-level doubly linked list, depth-first.

## Technique Reminder

Core singly/doubly linked list manipulation.

**Hint:** Draw the pointers on paper before coding; watch out for null pointers and losing references.

## Example

```
Input:  list with nested child sub-lists
Output: single flattened list, depth-first order
```
