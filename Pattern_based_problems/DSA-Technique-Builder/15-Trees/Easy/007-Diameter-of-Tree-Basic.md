# 007. Diameter of Tree Basic

**Topic:** Trees
**Difficulty:** Easy

## Problem

Given the root of a binary tree, find the length (in edges) of the longest path between any two nodes in the tree — the path may or may not pass through the root.

## Technique Reminder

Binary tree traversal and properties (DFS/BFS based).

**Hint:** Most tree problems are recursive: solve for the root using solutions of its subtrees.

## Example

```
Input:  tree = [1,2,3,4,5]
Output: 3
```
