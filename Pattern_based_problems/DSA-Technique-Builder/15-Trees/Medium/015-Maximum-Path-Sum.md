**Topic:** Trees
**Difficulty:** Medium
**Solution file:** [`015-Maximum-Path-Sum.java`](./015-Maximum-Path-Sum.java)

## Problem

Given the root of a binary tree, find the maximum path sum between any two nodes in the tree (the path does not need to pass through the root, and node values may be negative).

## Technique Reminder

Binary tree traversal and properties (DFS/BFS based).

**Hint:** Most tree problems are recursive: solve for the root using solutions of its subtrees.

## Example

```
Input:  tree = [-10,9,20,null,null,15,7]
Output: 42
```
