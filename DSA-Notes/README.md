# DSA-Notes

A structured, topic-by-topic set of Data Structures & Algorithms notes in Java, organized for interview prep.

## Recommended Template (applied to every topic)
1. **Theory** — What it is and why it exists.
2. **Internal Working** — How it works step by step.
3. **Complexity Analysis** — Time and space complexity.
4. **Visualization** — Diagrams or dry runs.
5. **Java Implementation** — From scratch and using built-in libraries (if applicable).
6. **Operations** — Insert, delete, search, update, traversal, etc.
7. **Real-World Applications** — Where it's used in software engineering.
8. **Common Patterns** — Frequently used techniques involving the data structure or algorithm.
9. **Practice Problems** — Easy → Medium → Hard (LeetCode, CSES, Codeforces).
10. **Interview Questions** — Conceptual and coding questions.
11. **Summary & Cheat Sheet** — Quick revision before interviews.

> Folders that split a topic across multiple files (e.g. `02-Arrays`, `06-Linked-List`)
> distribute these 11 sections across `Theory.md`, `Operations.md`, `Patterns.md`,
> `Problems.md`, `Interview.md`, and `Java-Implementation.java`. Folders with one file
> per algorithm (e.g. `05-Sorting`, `11-Graphs`) apply the full template inside each file.

## Structure
See the folder tree below — one folder per topic area, numbered in suggested study order.
Check `Resources/Practice-Roadmap.md` for a suggested week-by-week plan and
`18-Interview/` for interview-focused compilations.

## How to Use
1. Pick a topic folder in numeric order (see `Resources/Practice-Roadmap.md`).
2. Fill in the Theory/Internal Working sections first — write it in your own words.
3. Implement the Java code yourself before checking references.
4. Solve the linked practice problems Easy → Medium → Hard.
5. Revisit `CheatSheet.md` files before interviews for quick recall.
