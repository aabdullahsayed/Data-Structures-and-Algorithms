# 🚀 30-Day DSA Learning Plan (Problem-Solving Focused)

A structured, one-topic-per-day roadmap to build Data Structures & Algorithms skills through **hands-on problem solving** rather than passive theory reading.

## How This Plan Works

- **1 topic per day**, each in its own markdown file (`Day-01...` to `Day-30...`)
- Every day includes: learning objectives, a pattern-recognition tip, ~7 curated problems (mixed difficulty), an approach checklist, and an end-of-day review
- Problems are referenced by **name and difficulty** — search for them on your preferred judge (LeetCode, GeeksforGeeks, HackerRank, Codeforces) since exact links/wording vary by platform
- Spend **2–3 focused hours/day**: ~30-45 min reviewing the concept, the rest solving problems
- Use `progress-tracker.md` to log what you finish and what needs revisiting

## Suggested Daily Routine

1. Open the day's file and read the objectives + pattern tip (10 min)
2. Attempt problems in order — they're roughly sorted easy → hard (90-120 min)
3. For anything unsolved after 25-30 min of honest effort, look up the approach (not the full solution), then re-implement it yourself
4. Fill in the end-of-day checklist and progress tracker (5 min)

## Tips for Success

- **Don't skip the brute force.** Understanding why it's slow is what makes the optimal solution click.
- **Re-solve, don't just re-read.** If you looked up an approach, close the tab and code it from memory the next day.
- **Track patterns, not just problems.** The goal is pattern recognition — by Day 30 you should be able to glance at a new problem and guess which day's technique applies.
- **Weekly mini-revision:** every 7th day (7, 14, 21, 28), spend 20 minutes re-skimming the previous week's files before starting the new topic.
- **It's okay to take 2 days per topic** if a day feels rushed — consistency beats speed.
