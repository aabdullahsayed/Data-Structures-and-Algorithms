# Day 29: Trie & Bit Manipulation

**Topic area:** Trie / Bit Manipulation
**Time budget:** ~2–3 hours (45 min theory, rest problem solving)

## 🎯 Learning Objectives
- Trie construction for prefix-based string problems
- Bitwise operators: AND, OR, XOR, shifts
- Bit tricks: checking/setting/clearing bits, counting set bits

## 🧠 Pattern Recognition Tip
Look for: prefix matching over many strings, or O(1) bit-level tricks.

## 📝 Problems to Solve
1. **Implement Trie (Prefix Tree)** — `Medium`
2. **Word Search II (Trie + backtracking)** — `Hard`
3. **Single Number (XOR trick)** — `Easy`
4. **Number of 1 Bits** — `Easy`
5. **Counting Bits** — `Easy`
6. **Subsets using Bitmasking** — `Medium`
7. **Maximum XOR of Two Numbers in an Array** — `Medium`

## ✅ How to Approach Each Problem
1. Read the problem twice; restate it in your own words before coding.
2. Identify constraints (input size, value ranges) — they hint at the expected time complexity.
3. Write a brute-force solution first if the optimal approach isn't obvious.
4. Optimize using today's pattern; state the time & space complexity of your final solution.
5. Dry-run on the provided example plus one edge case (empty input, single element, all duplicates).
