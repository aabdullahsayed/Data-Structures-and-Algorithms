# Day 14: Linked List II — Advanced

**Topic area:** Linked List
**Time budget:** ~2–3 hours (45 min theory, rest problem solving)

## 🎯 Learning Objectives
- Merging & sorting linked lists
- Cycle detection with a starting point
- Deep copy with random pointers

## 🧠 Pattern Recognition Tip
Look for: pointer manipulation, no random access, in-place restructuring.

## 📝 Problems to Solve
1. **Reverse Linked List in Groups of K** — `Hard`
2. **Merge K Sorted Lists** — `Hard`
3. **Linked List Cycle II (find cycle start)** — `Medium`
4. **Add Two Numbers (as linked lists)** — `Medium`
5. **Copy List with Random Pointer** — `Medium`
6. **Sort a Linked List (Merge Sort)** — `Medium`
7. **Intersection of Two Linked Lists** — `Easy`

## ✅ How to Approach Each Problem
1. Read the problem twice; restate it in your own words before coding.
2. Identify constraints (input size, value ranges) — they hint at the expected time complexity.
3. Write a brute-force solution first if the optimal approach isn't obvious.
4. Optimize using today's pattern; state the time & space complexity of your final solution.
5. Dry-run on the provided example plus one edge case (empty input, single element, all duplicates).
