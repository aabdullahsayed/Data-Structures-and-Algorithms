# Day 6: Binary Search

**Topic area:** Searching
**Time budget:** ~2–3 hours (45 min theory, rest problem solving)

## 🎯 Learning Objectives
- Binary search on sorted arrays
- Binary search on answer (search space reduction)
- Handling duplicates & rotated arrays

## 🧠 Pattern Recognition Tip
Look for: sorted data, or a monotonic condition you can binary search over.

## 📝 Problems to Solve
1. **Classic Binary Search** — `Easy`
2. **Search in Rotated Sorted Array** — `Medium`
3. **Find First and Last Position of Element in Sorted Array** — `Medium`
4. **Find Peak Element** — `Medium`
5. **Median of Two Sorted Arrays** — `Hard`
6. **Koko Eating Bananas (binary search on answer)** — `Medium`
7. **Allocate Minimum Number of Pages** — `Hard`

## ✅ How to Approach Each Problem
1. Read the problem twice; restate it in your own words before coding.
2. Identify constraints (input size, value ranges) — they hint at the expected time complexity.
3. Write a brute-force solution first if the optimal approach isn't obvious.
4. Optimize using today's pattern; state the time & space complexity of your final solution.
5. Dry-run on the provided example plus one edge case (empty input, single element, all duplicates).
