# Day 3: Arrays III — Sliding Window

**Topic area:** Arrays / Sliding Window
**Time budget:** ~2–3 hours (45 min theory, rest problem solving)

## 🎯 Learning Objectives
- Fixed-size vs variable-size sliding window
- Expanding & shrinking window with two pointers
- Recognizing subarray/substring optimization problems

## 🧠 Pattern Recognition Tip
Look for: contiguous subarray/substring with a size or sum condition.

## 📝 Problems to Solve
1. **Maximum Sum Subarray of Size K** — `Easy`
2. **Longest Substring Without Repeating Characters** — `Medium`
3. **Minimum Size Subarray Sum** — `Medium`
4. **Longest Repeating Character Replacement** — `Medium`
5. **Fruit Into Baskets** — `Medium`
6. **Sliding Window Maximum** — `Hard`
7. **Find All Anagrams in a String** — `Medium`

## ✅ How to Approach Each Problem
1. Read the problem twice; restate it in your own words before coding.
2. Identify constraints (input size, value ranges) — they hint at the expected time complexity.
3. Write a brute-force solution first if the optimal approach isn't obvious.
4. Optimize using today's pattern; state the time & space complexity of your final solution.
5. Dry-run on the provided example plus one edge case (empty input, single element, all duplicates).
