# Day 1: Arrays I — Basics & Traversal

**Topic area:** Arrays
**Time budget:** ~2–3 hours (45 min theory, rest problem solving)

## 🎯 Learning Objectives
- Understand static vs dynamic arrays, memory layout
- Time complexity of insert/delete/access
- Basic traversal & in-place modification patterns

## 🧠 Pattern Recognition Tip
Look for: fixed input size, need for O(1) index access, in-place transformations.

## 📝 Problems to Solve
1. **Find the largest/smallest element in an array** — `Easy`
2. **Reverse an array in-place** — `Easy`
3. **Move all zeros to the end** — `Easy`
4. **Find the second largest element** — `Easy`
5. **Left rotate an array by D places** — `Medium`
6. **Find the missing number in an array of 1 to N** — `Easy`
7. **Find all duplicate elements in an array** — `Medium`

## ✅ How to Approach Each Problem
1. Read the problem twice; restate it in your own words before coding.
2. Identify constraints (input size, value ranges) — they hint at the expected time complexity.
3. Write a brute-force solution first if the optimal approach isn't obvious.
4. Optimize using today's pattern; state the time & space complexity of your final solution.
5. Dry-run on the provided example plus one edge case (empty input, single element, all duplicates).
