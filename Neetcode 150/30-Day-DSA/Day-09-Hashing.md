# Day 9: Hashing

**Topic area:** Hashing
**Time budget:** ~2–3 hours (45 min theory, rest problem solving)

## 🎯 Learning Objectives
- HashMap/HashSet operations and amortized O(1)
- Collision handling concepts
- Recognizing hashing-friendly problems (frequency, lookup)

## 🧠 Pattern Recognition Tip
Look for: fast lookup, counting frequency, detecting duplicates/pairs.

## 📝 Problems to Solve
1. **Two Sum** — `Easy`
2. **Subarray Sum Equals K (hashmap approach)** — `Medium`
3. **Longest Consecutive Sequence** — `Medium`
4. **Group Anagrams (hashmap approach)** — `Medium`
5. **Isomorphic Strings** — `Easy`
6. **Top K Frequent Elements** — `Medium`
7. **First Missing Positive** — `Hard`

## ✅ How to Approach Each Problem
1. Read the problem twice; restate it in your own words before coding.
2. Identify constraints (input size, value ranges) — they hint at the expected time complexity.
3. Write a brute-force solution first if the optimal approach isn't obvious.
4. Optimize using today's pattern; state the time & space complexity of your final solution.
5. Dry-run on the provided example plus one edge case (empty input, single element, all duplicates).
