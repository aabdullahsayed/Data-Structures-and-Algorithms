# Day 5: Sorting Algorithms

**Topic area:** Sorting
**Time budget:** ~2–3 hours (45 min theory, rest problem solving)

## 🎯 Learning Objectives
- Bubble, Selection, Insertion sort (O(n^2) family)
- Merge Sort & Quick Sort (O(n log n) family)
- Stability and in-place vs out-of-place sorting
- Counting sort / Bucket sort for special cases

## 🧠 Pattern Recognition Tip
Look for: 'sorted order helps', duplicates, or when output must be ordered.

## 📝 Problems to Solve
1. **Implement Merge Sort from scratch** — `Medium`
2. **Implement Quick Sort from scratch** — `Medium`
3. **Sort an array of 0s, 1s, and 2s** — `Easy`
4. **Merge Intervals** — `Medium`
5. **Kth Largest Element in an Array** — `Medium`
6. **Meeting Rooms II** — `Medium`
7. **Sort a nearly sorted (K-sorted) array** — `Medium`

## ✅ How to Approach Each Problem
1. Read the problem twice; restate it in your own words before coding.
2. Identify constraints (input size, value ranges) — they hint at the expected time complexity.
3. Write a brute-force solution first if the optimal approach isn't obvious.
4. Optimize using today's pattern; state the time & space complexity of your final solution.
5. Dry-run on the provided example plus one edge case (empty input, single element, all duplicates).
