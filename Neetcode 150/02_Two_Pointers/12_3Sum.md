# 12. 3Sum

**Difficulty:** Medium

**Pattern:** Sort + Two Pointers, fix one element at a time

## Key Idea
Sort the array, fix nums[i] as the smallest of the triplet, then use the two-pointer technique on the remaining subarray to find pairs summing to -nums[i].

## Approach
1. Sort nums ascending.
2. For i in range(n): skip duplicate i values; if nums[i] > 0 break early (no triplet possible).
3. Set left = i+1, right = n-1; while left < right, compute sum = nums[i]+nums[left]+nums[right].
4. If sum == 0, record triplet, then move both pointers and skip duplicates for left/right.
5. If sum < 0, left += 1; if sum > 0, right -= 1.

## Complexity
Time: O(n^2) | Space: O(1) extra (O(n) or O(log n) for sort, output not counted)

## Edge Cases
Must avoid duplicate triplets — careful duplicate-skipping logic at i, left, and right.

## Related / Notes
4Sum generalizes this with an extra outer loop or k-sum recursion.
